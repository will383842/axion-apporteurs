## PR #769 — 2026-10-07 — fix(GOV-062): la porte A rouvre — sharp 0.35.5 et source-map-js 1.2.2 au verrou, deux avis hauts fermés (REQ-QA-013)

**Fait.** Deux avis de gravité haute, publiés sur des dépendances de production de Next 16.3.8
(`source-map-js` 1.2.1 via `postcss`, et `sharp` 0.35.4), faisaient rougir l'audit de la porte A
sur toutes les PR. Les deux versions corrigées entraient déjà dans les plages déclarées par leurs
parents : seul le verrou change, et ni `package.json`, ni la version de Next, ni aucun override.

**Reste.** Un avis modéré, `fast-uri` 3.1.7 via `ajv`, reste ouvert : la porte A ne bloque qu'à
partir de la gravité haute, et il est laissé hors de cette PR exprès. L'entrée de registre de
l'audit dans `docs/gates.json`, déjà nommée comme dette par #313, n'est pas posée ici.

**Appris.** Monter la dépendance directe n'est pas toujours la plus petite montée : quand la
version corrigée tient dans la plage que déclare déjà le parent, une nouvelle résolution du verrou
suffit. Mais `pnpm update --depth Infinity <paquet>` réécrit aussi les plages de `package.json`
au passage ; il faut le restaurer, puis `pnpm install --lockfile-only` pour réaligner le verrou.
