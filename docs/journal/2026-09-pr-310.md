## PR #310 — 2026-09-30 — docs(QA-T13): la liste de mise en service nomme un porteur par case, exige le registre de l'entite et dit l'echappatoire remise a 0

**Fait.** Chaque case de la liste de mise en service dit maintenant qui fait le geste. La liste exige
que le registre de l'entité soit renseigné, sans aucune valeur bancaire dans le dépôt public. Elle
porte la compensation de la garde des données personnelles tant que celle-ci n'est pas armée, et
coche le déploiement déjà prouvé côté axion-ia. Pour l'échappatoire de migration, la documentation
dit ce que fait le code : elle est remise à 0, valeur inerte.

**Reste.** Cocher la double clé une fois son déploiement prouvé. Le témoin de la valeur inerte est
partiel : il essaie une autre valeur que 0.

**Appris.** Une liste de conditions sans porteur est une liste que personne ne coche. Et une phrase
de documentation plus stricte que le code crée un faux écart, qu'on finit par vouloir « corriger »
dans le code sans raison.
