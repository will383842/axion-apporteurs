## PR #449 — 2026-10-02 — feat(JUR-T48): Art. 23 du gabarit : « en la qualité suivante : {{APPORTEUR_QUALITE}} », pour une élision juste avec chaque qualité

**Fait.** L'art. 23 du gabarit dit « L'Apporteur déclare contracter en la qualité suivante :
{{APPORTEUR_QUALITE}}. ». La phrase reste juste quelle que soit la qualité rendue, y compris quand le
libellé commence par une voyelle.

**Reste.** Les valeurs de la qualité arrivent avec DM-50, qui attend la validation de leur liste par
Williams ; le témoin de cette PR se fonde sur la liste de l'acceptance.

**Appris.** Une variable insérée après une préposition doit être relue avec chacune de ses valeurs : une
seule commençant par une voyelle suffit à rendre la phrase fautive.
