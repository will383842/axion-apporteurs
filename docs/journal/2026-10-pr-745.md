## PR #745 — 2026-10-05 — feat(JUR-T63): la trace du courriel d'invitation porte la version de « Vos données dans la console »

**Fait.** Les versions publiées de la page « Vos données dans la console » forment une liste datée,
en ajout seul. La version portée par la trace d'un courriel d'invitation se dérive de son instant
d'envoi, contre cette liste, borne de publication incluse : c'est la page publiée à l'envoi, jamais
celle du dépôt au moment du test. Une invitation à un instant où aucune version n'est publiée est
refusée, et le compte n'est pas créé.

**Reste.** Le chemin d'un témoin voisin, dont les invitations partaient avant la publication, est
versé par le rattrapage suivant.

**Appris.** La date d'une version publiée se retrouve dans l'historique : en rejouant l'extraction de
la page sur chaque commit qui a touché le registre, on voit quand elle est devenue publiable, et
qu'elle n'a pas changé depuis.
