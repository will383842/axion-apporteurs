## PR #394 — 2026-10-02 — fix(GOV-140): le rapport de gov:inventaire n'est plus tronqué sur un pipe Linux

**Fait.** Le rapport JSON de `gov:inventaire` sort dans le rappel de son écriture, les modes du
script s'excluent, et un balayage des gardes vérifie qu'aucune autre n'écrit un JSON puis ne sort
sans attendre.

**Reste.** Lire le rouge Linux sur le run de la PR, puis remettre à jour #384 et #372.

**Appris.** Un vert local sous Windows ne dit rien d'une sortie lue par un pipe sous Linux : le
pipe y est asynchrone, et `process.exit` n'attend pas qu'il se vide.
